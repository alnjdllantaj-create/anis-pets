Politique de confidentialité

Dernière mise à jour : 8 novembre 2026

1. Visite du site

Anis est un site informatif hébergé sur Netlify. Lors du chargement des pages, l'hébergeur traite des requêtes techniques pouvant comprendre l'adresse IP, des informations de navigateur et l'heure, selon ses propres règles. Voir la politique de Netlify.

2. Préférence de langue

Votre choix peut être enregistré dans le stockage local du navigateur sous anis-lang pour votre prochaine visite. Vous pouvez l'effacer dans les données du site de votre navigateur. Si ce stockage est désactivé, le site reste utilisable sans mémoriser le choix.

3. Contact

Le formulaire ouvre un brouillon dans votre application de messagerie ; le site n'envoie pas lui-même le message automatiquement. Le brouillon ne part que si vous le vérifiez et l'envoyez. Les fournisseurs de messagerie de l'expéditeur et du destinataire traitent alors son contenu ; n'y inscrivez pas d'informations sensibles que vous ne souhaitez pas partager.

4. Services et liens externes

Les polices sont hébergées avec les fichiers du site. La version actuelle ne contient pas de scripts Google Analytics ou AdSense actifs. Les liens de sources et de partage ouvrent des services externes lorsque vous cliquez ; leurs propres politiques s'appliquent.

5. Questions et changements

Pour une question ou une demande de correction ou suppression d'un message envoyé, utilisez la page de contact. Cette page sera mise à jour si les services ou le fonctionnement changent ; vos droits peuvent varier selon la loi applicable.
